# Student Record Management System

A simple console-based Student Record Management System developed using Java.

## Features
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Exit Program

## Technologies Used
- Java
- OOP Concepts
- ArrayList

## How to Run
1. Install Java JDK.
2. Clone this repository.
3. Open the project in IntelliJ IDEA or VS Code.
4. Run the Main.java file.
